# MusicPlayer-Mino

终端音乐播放器（Rust + ratatui + rodio）。

## 配置（`mino.toml`）

启动时按「程序当前目录 → 可执行文件所在目录」的顺序查找 `mino.toml`（仓库根目录已带一份模板）：

```toml
music_directory = 'E:\MyMusic'   # 音乐目录
volume = 0.8                     # 启动时的初始音量，0.0 ~ 1.0
```

- 缺哪项就用哪项的默认值；删掉整个文件即全部用内置默认值。
- 写错不会让程序起不来：界面标题栏红字提示原因，同时音量会被夹紧到 `0.0 ~ 1.0`。
- 改完需**重启**生效；标题栏会显示当前实际加载的是哪个文件。
- 想加新配置项：往 `Config` 结构体加一个带默认值的字段（`impl Default` 里给值）即可，`mino.toml` 里就能覆盖。

## 快捷键

| 键          | 作用                                       |
| ----------- | ------------------------------------------ |
| 数字 + 回车 | 播放指定歌曲                               |
| `n` / `p`   | 下一首 / 上一首                            |
| 空格        | 暂停 / 继续                                |
| `m`         | 切换播放模式（顺序 → 列表循环 → 单曲循环） |
| `+` / `-`   | 音量加减（每步 0.05，范围 0.0 ~ 1.0）      |
| `j` / `k`   | 移动列表光标（回车播放）                   |
| `↑` / `↓`   | 滚动列表窗口                               |
| `q`         | 退出                                       |

音量在播放中随时可调，状态行实时显示百分比（归零时标红）。
